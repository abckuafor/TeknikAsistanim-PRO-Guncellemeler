# Teknik Servis PRO

Windows 10/11 x64 için portable teknik servis uygulamasının hazır EXE güncellemeleri.

İndirmek için [Releases](https://github.com/abckuafor/TeknikAsistanim-PRO-Guncellemeler/releases) bölümünü açın. Uygulama içinden Uygulama Güncellemeleri → Güncellemeleri Kontrol Et → Güncelle ve Yeniden Aç da kullanılabilir.

Eski sürümlerle güncelleme uyumluluğu için TeknikAsistanim_PRO.exe adlı dosya korunur; yeni görünen ad Teknik Servis PRO'dur. Her yayının kendi derleme/test kapsamını okuyun. Yeni Windows arayüzü ve gerçek aygıt testleri Linux derlemesiyle doğrulanmış sayılmaz.

Bu depoya kaynak kod, API anahtarı, müşteri bilgisi, Data veya Drivers arşivi yüklenmez. Güncelleme öncesinde Data ve Drivers klasörlerinizi koruyun.
