# Teknik Servis PRO 1.5.3 — Windows doğrulama sonucu

24.10.2026 03:13 (Türkiye saati)

## Yeni sonuç

Orijinal EXE, güncel Microsoft Defender ile GitHub'ın ayrı Windows Server 2025 ortamında tarandı: tehdit bulunmadı, tarama çıkışı 0.

Kullanıcıya sunulan orijinal GitHub ZIP'i taslak yayından tekrar indirildi ve SHA256 özeti doğrulandı. ZIP yeniden paketlenmedi: SHA256 `ae8dcb2409dc48a1153d33cf6532780ebf23ea5a3734bcbfc6ade5bc7c0eb8dd`. Aynı ZIP'in Microsoft Defender taraması: tehdit bulunmadı, çıkış 0.

ZIP'ten çıkarılan EXE'nin SHA256 özeti: `0e670b0bb5b4b9828a5f7bb145ab207fb404e125224c6d17a16945bebe8e6917`. Önceki kaynak/derleme/GitHub karşılaştırmasıyla eşleşir. Bu incelemede uygulama kodu veya EXE değiştirilmedi.

Tarama sonrasında bu ayrı ortamda uygulama çalıştırıldı. Ana WPF penceresi işletim sistemi pencere tanıtıcısı ve başlığıyla doğrulandı: **Teknik Servis PRO 1.5.3 — Teknik Servis**. Normal kapatma başarılı, çıkış kodu 0. Bu, başlatma ve kapatma kontrolüdür; tüm özelliklerin test edildiği anlamına gelmez.

Defender platformu: 4.18.26090.9; güvenlik zekâsı: 1.461.171.0. Windows 10/11 üzerinde bu yeni çalıştırma testi yapılmadı; test Windows Server 2025 GitHub-hosted runner'dadır. Fiziksel donanım, sürücü kurulumu, yazıcı/tarayıcı ve gerçek otomatik EXE değiştirme işlemleri bu kontrolde denenmedi.

## Önceki tespit hakkında

Kullanıcının bilgisayarında görülen Trojan:Script/Sabsik.FL.A!ml tespiti inkâr edilmiyor. Ayrı ortamdaki tespit çıkmayan sonuç, Microsoft'un yanlış alarm kararı veya bütün sistemlerde güvenlik garantisi değildir. Microsoft dosya inceleme başvurusu yapılmadı. Kullanıcının ortamındaki bulut koruması, güvenlik zekâsı ve politikaları farklı sonuç verebilir.

İndirmeden önce Windows Güvenliği → Virüs ve tehdit koruması → Koruma güncellemeleri → Güncelleştirmeleri denetle yolunu kullanın. Yeniden uyarı çıkarsa dosyayı çalıştırmayın; antivirüsü kapatmayın, istisna eklemeyin ve karantinadan geri yüklemeyin. Uygulama kod imzalama sertifikasıyla imzalı değildir; SmartScreen ayrıca uyarı verebilir.

## Teslim

Yalnızca bu kontrollerden geçen orijinal v1.5.3 yeniden yayımlandı. v1.5.0–v1.5.2 taslakta; otomatik yayın workflow'u kapalı kalır. Uygulamanın yeni yayımları otomatik kontrol etmesi korunur. ZIP içinde TeknikServis_PRO.exe vardır. Eski programı kapatıp mevcut klasöre çıkarın; Data ve Drivers klasörlerini silmeyin.
